# Sonora - Web Rating Lagu

## Menjalankan proyek
1. Jalankan Apache dan MySQL melalui XAMPP.
2. Import `Backend/database.sql` melalui phpMyAdmin.
3. Buka `http://localhost/tubes_WEbPro/Frontend/`.

## Akun demo
- Email: `admin@sonora.test`
- Password: `password`

Akun demo dapat mengelola CRUD lagu. Pengguna biasa dapat mendaftar dan memberi rating.

## Katalog lagu
Katalog lokal ditampilkan langsung dari data bawaan frontend. Aplikasi tidak memerlukan API eksternal atau API key.
